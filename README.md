# pocket-money-app
## Status
Early concept / planning stage.
Core ideas drafted, architecture being explored, implementation not started yet.

## Overview
pocket-money-app is a behaviour‑tracking system designed for guardians and children.
The goal is to allow guardians to log daily behaviour, generate weekly outcomes, calculate rewards, and manage basic authentication.

Right now, the project is in the idea + modelling phase.
The focus is on understanding the domain, defining system operations, and shaping the early design model before coding begins.

## Current Focus
Establishing the domain model (Guardian, Child, BehaviourEntry, WeeklyOutcome, RewardSetting, Streak)

Building the analysis model (software responsibilities)

Writing system operations from use cases (pre/post conditions)

Drafting the design model (services, repositories, controllers)
